# cpu-scheduling-simulation

# Моделювання алгоритмів планування процесів

Навчальний проєкт, присвячений моделюванню роботи алгоритмів планування процесів в операційних системах. У роботі реалізовано два класичні алгоритми планування та виконано їх порівняльний аналіз за основними характеристиками ефективності. Проєкт створено в межах дисципліни **«Введення до операційних систем»**. :contentReference[oaicite:0]{index=0}

---

## Реалізовані алгоритми

- **FCFS (First Come, First Served)** — невитісняльний алгоритм, у якому процеси виконуються в порядку їх надходження.
- **Round Robin (RR)** — витісняльний алгоритм із використанням кванта часу, що забезпечує більш справедливий розподіл процесорного часу між процесами. :contentReference[oaicite:1]{index=1}

---

## Можливості програми

- введення довільного набору процесів;
- налаштування часу надходження та часу виконання кожного процесу;
- налаштування кванта часу для алгоритму Round Robin;
- обчислення:
  - часу початку виконання;
  - часу завершення;
  - часу очікування;
  - повного часу виконання (Turnaround Time);
  - середнього часу очікування;
  - середнього часу виконання;
- побудова текстової діаграми Ганта;
- порівняння результатів роботи різних алгоритмів планування. :contentReference[oaicite:2]{index=2}

## Метрики, що обчислюються

| Метрика | Опис |
|----------|------|
| Arrival Time | час надходження процесу |
| Burst Time | очікуваний час виконання |
| Start Time | момент першого запуску процесу |
| Completion Time | момент завершення виконання |
| Waiting Time | час очікування в черзі |
| Turnaround Time | повний час перебування процесу в системі |

## Основні результати

У процесі тестування було продемонстровано відмінності між невитісняльним алгоритмом **FCFS** та витісняльним алгоритмом **Round Robin**.

Отримані результати показують, що:

- FCFS є простим у реалізації, однак може призводити до **ефекту конвою**, коли короткі процеси змушені тривалий час очікувати завершення довгого процесу.
- Round Robin забезпечує більш рівномірний розподіл процесорного часу між процесами, що дозволяє зменшити середній час очікування та покращити швидкість відгуку системи. :contentReference[oaicite:3]{index=3}
